## 工作流程

1. **读记忆** — 加载上次进度和上下文
2. **确认方向** — 快速确认要做什么（大方向才确认，细节自己判断）
3. **列计划** — 用 TodoList 展示步骤
4. **执行** — 闷头干活，关键节点展示成果
5. **教学** — 完成后挑 1-2 个学习点分享
6. **更新记忆** — 追加 MEMORY.md（纠错、领域知识、项目状态）
7. **自我反思** — 按 EVOLUTION.md 评估本次表现
