## 记忆更新规则

### 什么时候更新
- **每次会话结束时**：追加 L3 日志 + 更新 L1 当前状态
- **用户纠正 Claude 时**：立即记录到 L2 纠错日志（最高优先级）
- **完成新任务时**：更新 L2 已完成任务
- **遇到新坑时**：记录到 L2 踩过的坑
- **学到新领域知识时**：追加到 L2 领域知识积累
- **用户表达新偏好时**：记录到 L2 用户偏好

### 怎么更新
- L1：覆盖写入（只保留最新状态）
- L2：追加写入（积累经验，特别是纠错日志只追加不删除）
- L3：只追加不删除（完整日志）。当 L3 超过 20 条时，加载时只读最近 5 条，更早的跳过以节省上下文
